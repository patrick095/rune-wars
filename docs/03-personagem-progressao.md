# 03 — Personagem, Atributos e Progressão

## Nível máximo

- Nível máximo: 100.
- O personagem começa no nível 1.
- Cada nível ganho concede 4 pontos de atributo.
- O nível não dá poder direto.
- O poder vem dos pontos distribuídos, equipamentos, armas, acessórios e estratégia.

Total aproximado de pontos ganhos até o nível 100:

```text
99 níveis ganhos × 4 = 396 pontos
```

## Filosofia

O nível representa potencial, não poder automático.

Um jogador nível alto com distribuição ruim pode ser fraco.
Um jogador com build bem pensada pode ser competitivo mesmo com menor investimento.

## Atributos

Rune Wars possui 4 atributos principais.

## Força

Funções:

- Aumenta exclusivamente o dano.
- Pode ser requisito para usar armas pesadas.

Exemplos de armas com requisito de Força:

- Canhão
- Machado
- TNT
- Mosquete pesado
- Canhão Rúnico

Força não aumenta:

- HP
- Defesa
- Mobilidade
- Sorte

## Agilidade

Funções:

- Aumenta mobilidade.
- Aumenta quanto o personagem pode andar por turno.
- Aumenta velocidade de movimentação.
- Aumenta defesa.
- Pode ser requisito para armas e armaduras.

Exemplos de itens com requisito de Agilidade:

- Arco longo
- Funda
- Boomerangue
- Armaduras leves

Agilidade representa tanto evasão/mobilidade quanto capacidade defensiva.

## Vitalidade

Funções:

- Aumenta HP.
- Melhora recuperação/resistência contra debuffs como:
  - Sangramento
  - Envenenamento

Vitalidade alta torna o personagem mais resistente, mas não aumenta dano nem defesa direta.

Exemplo de filosofia:

Um jogador com 5000 de HP, mas sem Força, Agilidade ou Sorte, será resistente, porém terá pouco dano, pouca defesa, pouca mobilidade e baixa ativação rúnica.

## Sorte

Funções:

- Aumenta taxas de craft.
- Aumenta chance de obter itens raros.
- Aumenta chance de ativar Efeito Rúnico.
- Pode influenciar chance de aprimoramento.

Sorte é importante tanto para economia quanto para PvP.

No PvP, Sorte representa poder tático, pois efeitos rúnicos podem mudar o resultado de uma jogada.

Exemplos:

- Cegar inimigo.
- Imobilizar.
- Sangrar.
- Remover mira.
- Limitar força do tiro.
- Teleportar inimigo aleatoriamente.

## Tipos de build

### Build de dano físico

Foco:

- Força
- Agilidade moderada
- Vitalidade moderada
- Sorte baixa/moderada

### Build tática/rúnica

Foco:

- Sorte
- Agilidade
- Vitalidade
- Força moderada

### Build tank

Foco:

- Vitalidade
- Agilidade
- Defesa por equipamentos

### Build escavador

Foco:

- Armas com escavação
- Mobilidade
- Resistência
- Controle de terreno

### Build engenheiro

Foco:

- Construção de terreno
- Agilidade
- Sorte
- Suporte estratégico

### Build artesão/coletor

Foco:

- Sorte
- Vitalidade suficiente para participar de dungeons e eventos
- Equipamentos de progressão

## Raças

Raças são fixas e dão bônus pequenos.

As raças não devem criar vantagem direta forte no PvP.

Foco dos bônus raciais:

- Progressão
- Craft
- Drop
- Economia

Exemplos:

### Humano

- +5% XP

### Anão

- +5% sucesso de craft/aprimoramento

### Elfo

- +5% chance de obter materiais raros

## Regras de balanceamento de atributos

- Nenhum atributo deve ser inútil.
- Nenhum atributo deve ser obrigatório para todas as builds.
- Todos os atributos devem criar escolhas reais.
- Atributos devem ter impacto, mas não podem eliminar habilidade do jogador.

## Força de combate

O matchmaking deve considerar um valor de força de combate.

Componentes possíveis:

- Pontos de atributo distribuídos
- Qualidade dos equipamentos
- Nível dos equipamentos
- Armas equipadas
- Acessórios
- Histórico/ranking recente
- Nível do personagem

Importante:

O nível não dá poder direto, mas pode ser usado como indicador auxiliar.
