## Módulos Backend (NestJS — app.module.ts)

- **AuthModule** — autenticação JWT, registro e login
- **CharacterModule** — criação de personagem, raça, atributos
- **InventoryModule** — inventário do jogador
- **InventorySlotsModule** — slots de inventário e equipamentos
- **DungeonModule** — dungeon multiplayer (lobby, sessões)
- **DungeonFloorsModule** — andares 1–5 com trilhas de dificuldade
- **BattleModule** — batalhas PvE e PvP, registro de resultados
- **ProgressionModule** — XP, level-up automático, histórico
- **RankedModule** — partidas ranqueadas, cálculo de rating
- **RankingsModule** — rankings diário/semanal/mensal/geral
- **CraftModule** — craft de itens com 10 receitas, influência de Sorte
- **UpgradeModule** — upgrade de itens +1 a +10 (item nunca quebra)
- **MarketModule** — listagem, compra, venda, taxa de 5%
- **GuildsModule** — criação de guilda, XP de guilda, banco, chat em tempo real

## Critérios de Aceite v1.0.0

- Jogador cria conta, escolhe raça, distribui atributos iniciais
- XP e level-up funcionam automaticamente
- Ranking ranqueado atualiza após cada partida
- Rankings diário/semanal/mensal/geral funcionam
- Andares 1–5 com 4 trilhas de dificuldade
- Dungeon multiplayer com até 4 jogadores (lobby)
- Craft de 10 receitas com influência de Sorte

- Mercado lista, vende e taxa 5% corretamente
- Guilda criada, XP de guilda, banco acessível, chat em tempo real
- Sistema anti-pay-to-win: nenhum item de poder vendido por dinheiro real

## Como Rodar o Projeto

### Pré-requisitos
- Docker e Docker Compose instalados
- Node.js 20+ (para desenvolvimento local)

### Produção (Docker)

```bash
# Na pasta devops/
cp .env.example .env
# Edite .env com valores de produção (especialmente JWT_SECRET)
docker-compose up -d
```

Serviços disponíveis:
- Frontend: http://localhost:4200
- Backend API: http://localhost:3000
- Health check: http://localhost:3000/health
- PostgreSQL: localhost:5432
- Redis: localhost:6379

### Desenvolvimento Local (sem Docker)

```bash
# Backend
cd system/backend
npm install
npm run start:dev

# Frontend (outro terminal)
cd system/frontend
npm install
npm start
```

### Variáveis de Ambiente (.env)

```env
ANGULAR_ENV=development
API_URL=http://localhost:3000
NODE_ENV=development
PORT=3000
JWT_SECRET=change-me-in-production
JWT_EXPIRES_IN=7d
POSTGRES_HOST=postgres
POSTGRES_PORT=5432
POSTGRES_DB=runewars
POSTGRES_USER=rw_user
POSTGRES_PASSWORD=rw_pass
REDIS_HOST=redis
REDIS_PORT=6379
```
