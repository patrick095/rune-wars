## Decisões e assunções

- Assets de personagem usam fallback (placeholder) — assets definitivos são pipeline separado
- `MapModifier` usa círculos Graphics como placeholder visual
- `combat-hud.ts` e `power-meter-hud.ts` mantidos intactos (rollback seguro)
- Todas as alterações em `battle.scene.ts`, `academy.scene.ts`, `dungeon.scene.ts` marcadas com `// [v1.5.0]`
- Bundle de 3.04 MB causado pelo Phaser.js (CommonJS, não ESM) — não reduzível sem trocar library
