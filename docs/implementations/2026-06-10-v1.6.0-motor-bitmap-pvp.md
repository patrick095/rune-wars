# v1.6.0 — Motor de Mapa Bitmap + Terrain Destrutível

**Data:** 2026-06-10

## Objetivo

Substituir o motor de terrain baseado em grade (tiles 8×8px / grid 450×160) por um sistema bitmap pixel-perfect. As imagens PNG reais dos mapas PVP passam a ser usadas diretamente. Explosões cortam buracos circulares via `RenderTexture.erase()`. Colisão lê o canal alpha do PNG via `Uint8Array`. 12 spawn points por mapa em coordenadas de pixel. 5 mapas PVP suportados.

## Decisões técnicas

| Decisão | Motivo |
|---------|--------|
| `castle` renomeado para `mystic_castle` | Assets estão em pasta `mystic-castle/` |
| Dimensões fixas 1672×941 para todos os 5 mapas | Matching com terrain PNGs |
| `CELL_SIZE` mantido como alias = 1 `@deprecated` | Evitar quebrar imports não mapeados |
| `GRID_COLS`/`GRID_ROWS` mantidos como aliases `@deprecated` | Compatibilidade com dungeon.scene.ts |
| `terrain-textures.ts` deletado | Tiles gerados não são mais necessários |
| Decodificador PNG nativo em `analyze-spawns.mjs` | Pacote `canvas` não disponível sem package.json na raiz |
