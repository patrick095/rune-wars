# Rune Wars v1.2.0 — Assets Visuais, Inventário, Cofre, Mapas e Fixes de Gameplay

**Data:** 2026-06-08
**Status:** Completo — builds passando sem erros TypeScript

---

## Resumo

A v1.2.0 entregou um build jogável e testável por beta testers, adicionando ~49 assets visuais, power meter funcional, ghost trace, inventário 6x6 com slots de equipamento, cofre 6x10 compartilhado com taxa de retirada, 5 mapas de batalha (incluindo 3 novos), paridade desktop=playground, e canvas único sem navegação Angular.

### 3. Sistema de Inventário (Frontend)

**Componentes criados em** `src/app/shared/components/`:

| Componente | Descrição |
|-----------|-----------|
| `inventory-grid/` | Grid 6x6 (36 slots) para inventário do personagem |
| `equipment-slots/` | Slots de equipamento por tipo (arma, armadura, capacete, etc.) |
| `item-slot/` | Slot individual com drag-and-drop nativo HTML5 e tooltip |

### 4. Cofre Compartilhado (Backend + Frontend)

**Backend** — `system/backend/src/vault/`

| Arquivo | Descrição |
|---------|-----------|
| `vault.entity.ts` | Entidade cofre no banco de dados |
| `vault-slot.entity.ts` | Slot individual do cofre |
| `vault.service.ts` | Lógica de negócio: depósito/retirada de itens e ouro |
| `vault.controller.ts` | Endpoints REST do cofre |
| `vault.module.ts` | Módulo NestJS |
| `dto/deposit-item.dto.ts` | DTO depósito de item |
| `dto/withdraw-item.dto.ts` | DTO retirada de item |
| `dto/deposit-gold.dto.ts` | DTO depósito de ouro |
| `dto/withdraw-gold.dto.ts` | DTO retirada de ouro |

**Taxa de retirada de ouro:** 3% fixo (ex.: retirar 100 gold custa 103 gold do cofre).
**Taxa de retirada de item:** taxa fixa constante `VAULT_ITEM_FEE` definida em `vault.service.ts`.

**Frontend** — `src/app/shared/services/vault.service.ts`
- Integração com API do backend para operações do cofre.

### 5. Mapas de Batalha

**5 mapas no total** — `src/app/shared/game-core/maps/`:

| Arquivo | Bioma |
|---------|-------|
| `map-plains.json` | Planícies (existia antes) |
| `map-castle.json` | Castelo (existia antes) |
| `map-deep-mines.json` | Minas Profundas (novo) |
| `map-arcane-ruins.json` | Ruínas Arcanas (novo) |
| `map-runic-forest.json` | Floresta Rúnica (novo) |

Formato: `{ "grid": number[][] }` com valores 0 (vazio), 1 (sólido), 2 (material escavável).

`battle.scene.ts` define o tipo `MapName = 'plains' | 'castle' | 'deep_mines' | 'arcane_ruins' | 'runic_forest'` e expõe o método `switchMap(mapName: MapName)`.

### 6. Paridade Desktop = Playground

**`dungeon.scene.ts`** e **`academy.scene.ts`** usam `this.scale.width/height` para layout responsivo e `scale.on('resize', ...)` para re-renderizar ao redimensionar.

**`app.component.ts`** — subscreve ao `openScreen$` e abre a tela Angular correspondente ao POI clicado no hub.

## Decisões de Implementação

- Assets são placeholders gerados programaticamente (PNG com cor sólida/gradiente) — suficientes para testes funcionais.
- Drag-and-drop usa API nativa HTML5, sem Angular CDK.
- Taxa de cofre: 3% no ouro, fee fixo em itens.
- Ghost trace apaga ao iniciar o turno do próprio jogador (padrão do gênero).
- Mapas usam grid numérico simples: 0=vazio, 1=sólido, 2=escavável.
