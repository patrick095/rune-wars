# v1.2.0 — Melhorias de Gameplay PvP

**Data:** 2026-06-08

## Objetivo

Implementar melhorias de gameplay PvP definidas no spec v1.2.0: mapas grandes com spawn aleatório, movimentação por orçamento, colisão horizontal, morte por queda, facing + sprite flip, câmera com scroll e renderização via RenderTexture estilo DDTank/Gunbound.

---

## O que foi implementado

### Agent 001 — Engine Foundation
- `GRID_COLS` 100 → 300, `GRID_ROWS` 40 → 80
- Interface `MapMeta` exportada com `name`, `cols`, `rows`, `spawnPoints`
- Getters `worldWidth` / `worldHeight` em `TerrainEngine`
- `CharacterFall.update()` agora retorna `'alive' | 'dead'`, queda contínua em abismos, morte após 3s

### Agent 002 — New Helper Files
- `terrain-collision.ts`: `tryHorizontalMove()` com step climbing ≤12px
- `spawn-selector.ts`: `selectSpawns()` (Fisher-Yates), `spawnToWorld()`, `moveSpeed()`, `moveBudget()`
- `movement-budget-hud.ts`: Barra de progresso de movimento por turno

### Agent 003 — Terrain Renderer Rewrite
- `terrain-renderer.ts` reescrito com `RenderTexture` (depth 2) + background `Rectangle` (depth 0)
- `updateCells()` apaga pixels destruídos individualmente via `rt.fill(..., 0)`
- `setMapName()` troca paleta visual por mapa

### Agent 004 — Terrain Textures
- `terrain-textures.ts`: texturas procedurais via Phaser Graphics (sem PNGs externos)
- Paletas por mapa: plains, castle, deep_mines, arcane_ruins, runic_forest, dungeon
- `CELL_SIZE = 8px` confirmado (não 20 como o spec assumia)

### Agents 005 e 006 — Maps JSON
- 5 mapas PvP gerados: plains, castle, deep_mines, arcane_ruins, runic_forest (300×80 células)
- 3 mapas dungeon: cave-entrance, cave-hall (200×60), cave-boss (200×70)
- Todos com campo `meta.spawnPoints` (12 spawns PvP, 4-6 spawns dungeon)

### Agent 007 — BattleScene Integration
- Spawn aleatório com `selectSpawns()` + `spawnToWorld()` do meta do mapa
- `movePlayer()`: usa `tryHorizontalMove`, respeita orçamento de movimento por turno
- `handleKeyboardInput()`: velocidade por `moveSpeed(agility)` em vez de constante
- `getWorldAngle()`: ângulo espelhado por facing para tiro e preview de trajetória
- `facing` em `BattleCharacterState`, flip de avatar ao mudar direção
- `CharacterFall.update()` integrado com detecção de morte
- Câmera com bounds + follow suave (lerp 0.08) seguindo ativo (player/IA)
- `MovementBudgetHUD` visível no turno do jogador, oculta no turno da IA
- `setPlayerAgility()` adicionado à debug API
- `switchMap()` reseta bounds da câmera e faz re-spawn

### Agent 008 — Debug Overlay
- Slider de agilidade (0-500) na seção Combate
- `onReset()` reseta playerAgility para 50

## Decisões técnicas

- `CELL_SIZE = 8px` (não 20px como o spec estimava) — mantido conforme o código existente
- Mundo PvP: 2400×640px (300×80 células × 8px)
- `playerSprite` mantido como `Rectangle` para física/colisão; `playerAvatar` (Image) para visuais e flip
- `_initialized` singleton no `terrain-textures.ts` — idempotente por `scene.textures.exists(key)`
- `scene.make.graphics({ add: false })` removido — propriedade `add` não existe no type do Phaser 3
