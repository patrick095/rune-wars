# Spec de Implementação — v1.6.0: Motor de Mapa com Assets Reais e Terreno Destrutível por Pixel

---

## 1. Resumo

Substituição completa do motor de mapa baseado em grade (tiles 8×8px) por um sistema de terreno baseado em bitmap de pixels. As imagens reais dos mapas (`background.png` + `terrain.png` em `assets/maps/`) passam a ser usadas diretamente: o background é estático, o terrain é renderizado em um `RenderTexture` do Phaser, e explosões cortam buracos circulares no terrain usando o modo de mesclagem `ERASE`. A detecção de colisão lê diretamente o canal alpha do bitmap do terrain (pixel-perfect), eliminando a grade de células. Também são definidos 12 spawn points por mapa PVP, com coordenadas em pixels (espaço de mundo).

---

## 2. Pedido Original

> "Quero uma melhoria em todo o motor do mapa para usar assets reais. Utilize os assets dos mapas em `system/frontend/src/assets/maps`, que contêm o background e terrain de cada mapa. Não quero mais o mapa sendo renderizado por pequenos quadradinhos. Quando houver explosão que destruir parte do mapa deve apenas recortar aquele pedaço. Vai precisar mapear exatamente cada ponto dos terrains para detectar colisão. Faça de forma que funcione como Gunbound, DDTank ou Worms. Vai precisar analisar as imagens dos mapas e decidir os 12 spawn points de cada mapa. Por enquanto somente para PVP."

---

## 3. Problema a Resolver

- O terrain atual é renderizado como uma grade de tiles coloridos 8×8px — visualmente primitivo e desconectado dos assets de mapa existentes.
- A colisão é baseada em células de grade: baixa fidelidade, bordas retas que não refletem a forma orgânica do terrain real.
- Explosões destroem blocos quadrados inteiros (8px), não círculos suaves.
- Os backgrounds dos mapas já funcionam como imagens PNG, mas o terrain (primeiro plano jogável) não.
- Existe inconsistência de nomenclatura: o mapa `castle` no código usa assets em `mystic-castle/`.
- Os arquivos JSON de mapa carregam arrays `grid` massivos (>140KB cada), desperdiçando memória e tempo de parse.

---

## 4. Objetivo da Implementação

1. Renderizar o terrain de cada mapa PVP usando a imagem `terrain.png` real.
2. Implementar colisão pixel-perfect: sólido onde alpha do terrain PNG > 127, vazio onde alpha ≤ 127.
3. Explosões cortam buracos circulares suaves na imagem de terrain (sem destruição em blocos).
4. Eliminar os arrays `grid` dos JSONs de mapa PVP; substituir por spawn points em coordenadas de pixel.
5. Definir 12 spawn points por mapa PVP, posicionados sobre superfície sólida.
6. Padronizar nomenclatura de mapas (resolver `castle` ↔ `mystic-castle`).

## 6. Pesquisa e Referências

### O que foi pesquisado
- Técnicas de terrain destrutível em jogos 2D (Worms, Gunbound, DDTank)
- Phaser 3: RenderTexture com ERASE blend mode
- Phaser 3: detecção de colisão pixel-perfect com PNG
- Implementações open-source de terrain destrutível em Phaser

### Pontos relevantes encontrados

**Técnica central (Worms/Gunbound/DDTank):**
- Mantêm um **bitmap de colisão em memória** (`Uint8Array` ou `Uint8ClampedArray`): 1 byte por pixel.
- Colisão: sample no bitmap em (floor(x), floor(y)) — se sólido, há colisão.
- Destruição: zera pixels dentro de raio circular no bitmap + atualiza visual simultaneamente.
- Visual separado do lógico: bitmap na RAM (colisão), RenderTexture na GPU (visual).

**Phaser 3 — buracos em RenderTexture:**
- `RenderTexture.erase(source, x, y)`: apaga pixels do RT usando a forma do `source` como máscara.
- `Graphics` circle (filled, cor qualquer) como brush de apagamento → cria buracos circulares suaves.
- Phaser 3.85+ inclui exemplo oficial "Erase Part Of Render Texture Canvas".
- Performance excelente: operação GPU, não rebuilda o RT inteiro.

**Phaser 3 — colisão pixel-perfect:**
- Phaser arcade physics NÃO suporta pixel-perfect nativamente.
- Abordagem correta: ler `ImageData` do PNG via canvas oculto na carga, guardar como `Uint8Array` flat, samplear por coordenada.
- Coordenadas devem ser inteiras (`Math.floor`) — `getPixel` falha com floats.

### O que será aproveitado
- Técnica de bitmap duplo (colisão RAM + visual GPU) — padrão da indústria.
- `RenderTexture.erase()` com `Graphics` circular como brush.
- Leitura de ImageData via canvas oculto no preload do Phaser.

### O que foi descartado e por quê
- **Quad-tree de polígonos (tesselação):** overkill para este projeto; a abordagem bitmap é mais simples e suficiente para ~1672×941 pixels.
- **Phaser arcade physics pixel-perfect:** não existe; mantemos colisão manual já existente.
- **Partículas por pixel destruído:** custo de performance não justificado; futuramente pode-se adicionar VFX de explosão sobre o buraco.

## 7. Decisões Tomadas

| Decisão | Escolha | Motivo |
|---------|---------|--------|
| Dimensões do mundo | **1672×941 px** (matching terrain PNG) | Elimina escalonamento; coordenadas 1:1 com bitmap |
| Colisão | **Bitmap pixel-perfect** (`Uint8Array`) | Fidelidade total ao shape do terrain real |
| Visual terrain | **RenderTexture + ERASE** | Padrão Phaser, GPU, sem rebuild de chunks |
| Indestructible terrain | **Fora do escopo PVP** (todos pixels com alpha>127 = destrutível) | PVP maps não possuem áreas indestructible por design |
| Spawn points | **Coordenadas de pixel (x, y)** no espaço de mundo | Direto, sem conversão col/row |
| Nomenclatura `castle` | **Renomear para `mystic-castle`** no código | Consistência com pasta de assets |
| JSONs de mapa | **Remover campo `grid`**; manter apenas `meta` com spawn points | Redução de ~140KB por arquivo |
| runic-forest background | **Escalar background para 1672×941** | Consistência; terrain já está em 1672×941 |
| CELL_SIZE | **Deprecar** (manter apenas como alias = 1 para compatibilidade temporária) | Colisão pixel não usa células |

## 10. Regras de Negócio

1. **Terrain sólido:** todo pixel com alpha > 127 na `terrain.png` é sólido e destrutível.
2. **Terrain vazio:** pixels com alpha ≤ 127 são espaço livre (céu, transparência).
3. **Explosão:** apaga pixels dentro do raio circular no bitmap de colisão E no RenderTexture.
4. **Character fall:** personagem cai quando não há pixel sólido diretamente abaixo dos seus pés.
5. **Spawn points:** devem estar em posição com pixel sólido imediatamente abaixo (no máximo 5px de ajuste automático).
6. **Constructed terrain (runic builder):** permanece como funcionalidade independente; deve funcionar com a nova arquitetura.
7. **Mundo por mapa:** todos os 5 mapas PVP usam dimensões 1672×941.

## 11. Fluxo do Usuário

```
Entra em batalha PVP
→ Phaser preload: carrega background.png + terrain.png do mapa selecionado
→ TerrainEngine.fromImage(): lê pixels do terrain PNG → cria Uint8Array de colisão
→ TerrainRenderer: renderiza background + terrain no RenderTexture
→ Personagens spawnados em posições pixel com chão válido
→ [turno]
→ Jogador move personagem → terrain-collision lê bitmap → movimenta
→ Jogador atira → projétil voa → colisão testada no bitmap a cada frame
→ Impacto → TerrainEngine.explode(cx, cy, radius) → apaga pixels no bitmap
→ TerrainRenderer recebe notificação → aplica ERASE circular no RenderTexture
→ Buraco visível no terrain; background aparece por baixo
→ [próximo turno]
```

### Arquitetura do novo motor de terreno

```
terrain.png (RGBA)
    ↓ canvas oculto (preload)
    ↓ getImageData()
    ↓
TerrainBitmap (Uint8Array, 1 byte/pixel)
    ├── isSolid(x, y): boolean        ← colisão
    └── clearCircle(cx, cy, r): void  ← destruição

TerrainEngine (refatorado)
    ├── construtor: aceita TerrainBitmap
    ├── getMaterialAt(wx, wy): TerrainMaterial  ← lê bitmap
    ├── explode(cx, cy, r): ExplosionResult
    ├── getFloorBelow(wx, wy): number | null
    └── worldWidth, worldHeight (da dimensão do bitmap)

TerrainRenderer (refatorado)
    ├── bg: Phaser.GameObjects.Image (background.png, depth=-1)
    ├── rt: Phaser.GameObjects.RenderTexture (terrain.png, depth=0)
    ├── eraseBrush: Phaser.GameObjects.Graphics (círculo, reusado)

```

### Detalhes de implementação críticos

#### TerrainBitmap / TerrainEngine

```typescript
// terrain-engine.ts (novos internals)
export const WORLD_WIDTH = 1672;
export const WORLD_HEIGHT = 941;

export class TerrainEngine {
  private bitmap: Uint8Array; // 1 byte/pixel: 1=sólido, 0=vazio
  private width: number;
  private height: number;

  // Carrega a partir de ImageData (lido no Phaser preload)
  static fromImageData(data: ImageData): TerrainEngine { ... }

  getMaterialAt(wx: number, wy: number): TerrainMaterial {
    const x = Math.floor(wx);
    const y = Math.floor(wy);
    if (x < 0 || x >= this.width || y < 0 || y >= this.height) return TerrainMaterial.EMPTY;
    return this.bitmap[y * this.width + x] ? TerrainMaterial.DESTRUCTIBLE : TerrainMaterial.EMPTY;
  }

  explode(cx: number, cy: number, radius: number): ExplosionResult {
    // Zera pixels no círculo; retorna bounding box da área afetada
    const r2 = radius * radius;
    for (let dy = -radius; dy <= radius; dy++) {
      for (let dx = -radius; dx <= radius; dx++) {
        if (dx*dx + dy*dy <= r2) {
          const px = Math.floor(cx + dx);
          const py = Math.floor(cy + dy);
          if (px >= 0 && px < this.width && py >= 0 && py < this.height) {
            this.bitmap[py * this.width + px] = 0;
          }
        }
      }
    }
    return { center: {x: cx, y: cy}, radius };
  }

  getFloorBelow(wx: number, wy: number): number | null {
    const x = Math.floor(wx);
    const startY = Math.floor(wy);
    for (let y = startY; y < this.height; y++) {
      if (this.bitmap[y * this.width + x]) return y;
    }
    return null;
  }
}
```

#### TerrainRenderer — erase

```typescript
// terrain-renderer.ts (novos internals)
export class TerrainRenderer {
  private bg: Phaser.GameObjects.Image;
  private rt: Phaser.GameObjects.RenderTexture;
  private eraseBrush: Phaser.GameObjects.Graphics;

  constructor(scene: Phaser.Scene, bgKey: string, terrainKey: string) {
    this.bg = scene.add.image(WORLD_WIDTH/2, WORLD_HEIGHT/2, bgKey)
      .setDisplaySize(WORLD_WIDTH, WORLD_HEIGHT).setDepth(-1);

    this.rt = scene.add.renderTexture(0, 0, WORLD_WIDTH, WORLD_HEIGHT)
      .setDepth(0).setOrigin(0, 0);
    this.rt.draw(terrainKey, 0, 0);  // desenha terrain PNG no RT

    this.eraseBrush = scene.make.graphics({ add: false });
  }

  applyExplosion(cx: number, cy: number, radius: number): void {
    this.eraseBrush.clear();
    this.eraseBrush.fillStyle(0xffffff, 1);
    this.eraseBrush.fillCircle(radius, radius, radius);
    this.rt.erase(this.eraseBrush, cx - radius, cy - radius);
  }
}
```

```typescript
// Mapeamento slug de mapa para pasta de assets
const MAP_ASSET_FOLDER: Record<string, string> = {
  plains:         'plains',
  mystic_castle:  'mystic-castle',
  deep_mines:     'deep-mines',

preload(): void {
  const folder = MAP_ASSET_FOLDER[this.currentMap];
  this.load.image(`map_${this.currentMap}_bg`,      `assets/maps/${folder}/background.png`);
  this.load.image(`map_${this.currentMap}_terrain`,  `assets/maps/${folder}/terrain.png`);
  // ... demais assets (personagens, armas, etc.)
}
```

#### Leitura do bitmap no create()

```typescript
create(): void {
  // Lê pixel data da textura de terrain carregada
  const terrainKey = `map_${this.currentMap}_terrain`;
  const imgData = this.getTerrainImageData(terrainKey);
  this.terrainEngine = TerrainEngine.fromImageData(imgData);
  // ...
}

private getTerrainImageData(key: string): ImageData {
  const source = this.textures.get(key).getSourceImage() as HTMLImageElement;
  const canvas = document.createElement('canvas');
  canvas.width = source.naturalWidth;
  canvas.height = source.naturalHeight;
  const ctx = canvas.getContext('2d')!;
  ctx.drawImage(source, 0, 0);
  return ctx.getImageData(0, 0, canvas.width, canvas.height);
}
```

## Apêndice A — Script de Análise de Spawn Points

```javascript
// tools/analyze-spawns.mjs
// Uso: node tools/analyze-spawns.mjs
// Requer: npm install canvas (no diretório raiz)

import { createCanvas, loadImage } from 'canvas';

const MAPS = [
  { id: 'plains',        folder: 'plains' },
  { id: 'mystic_castle', folder: 'mystic-castle' },
  { id: 'deep_mines',    folder: 'deep-mines' },
  { id: 'arcane_ruins',  folder: 'arcane-ruins' },
  { id: 'runic_forest',  folder: 'runic-forest' },
];

const ALPHA_THRESHOLD = 127;
const MIN_FLAT_RUN = 40;      // px de chão plano mínimo para ser candidato
const MIN_CLEARANCE = 80;     // px de espaço livre acima do spawn
const N_SPAWNS = 12;

async function analyzeMap(folder) {
  const img = await loadImage(`system/frontend/src/assets/maps/${folder}/terrain.png`);
  const { width, height } = img;
  const canvas = createCanvas(width, height);
  const ctx = canvas.getContext('2d');
  ctx.drawImage(img, 0, 0);
  const data = ctx.getImageData(0, 0, width, height).data;

  const isSolid = (x, y) => {
    if (x < 0 || x >= width || y < 0 || y >= height) return false;
    return data[(y * width + x) * 4 + 3] > ALPHA_THRESHOLD;
  };

  const candidates = [];

  for (let y = MIN_CLEARANCE; y < height - 10; y++) {
    let runStart = -1;
    for (let x = 20; x < width - 20; x++) {
      const solid = isSolid(x, y) && !isSolid(x, y - 1);
      if (solid) {
        if (runStart < 0) runStart = x;
      } else {
        if (runStart >= 0 && x - runStart >= MIN_FLAT_RUN) {
          // Verificar clearance acima
          const midX = Math.floor((runStart + x) / 2);
          let hasClearance = true;
          for (let dy = 1; dy <= MIN_CLEARANCE; dy++) {
            if (isSolid(midX, y - dy)) { hasClearance = false; break; }
          }
          if (hasClearance) {
            candidates.push({ x: midX, y: y - 1, runLen: x - runStart });
          }
        }
        runStart = -1;
      }
    }
  }

  // Selecionar 12 candidatos bem distribuídos horizontalmente
  const sorted = candidates.sort((a, b) => a.x - b.x);
  const selected = [];
  const step = width / N_SPAWNS;
  for (let i = 0; i < N_SPAWNS; i++) {
    const targetX = step * i + step / 2;
    const closest = sorted.reduce((best, c) =>
      Math.abs(c.x - targetX) < Math.abs(best.x - targetX) ? c : best
    , sorted[0]);
    if (closest && !selected.find(s => Math.abs(s.x - closest.x) < 60)) {
      selected.push(closest);
    }
  }

  return selected.slice(0, N_SPAWNS).map(s => ({ x: s.x, y: s.y }));
}

for (const map of MAPS) {
  const spawns = await analyzeMap(map.folder);
  console.log(`\n// ${map.id}`);
  console.log(JSON.stringify({ spawnPoints: spawns }, null, 2));
}
```
