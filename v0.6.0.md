# v0.6.0 — Efeitos Rúnicos e Consumíveis

> **Status:** Planejado
> **Fase:** 5 + 6 — Crítico como Efeito Especial + Estratégia de PvP
> **Depende de:** [v0.5.0](./v0.5.0.md)
> **Objetivo:** Substituir o crítico tradicional por efeitos rúnicos especiais, e adicionar itens secundários e consumíveis para aumentar a profundidade estratégica do PvP.

---

## 1. Resumo

Esta versão transforma o combate em algo estrategicamente rico. Cada arma pode ativar seu efeito rúnico baseado na Sorte do jogador — não é só mais dano, são debuffs e estados que mudam o rumo da batalha. Além disso, itens secundários e consumíveis entram no jogo, com regras claras de uso por turno.

---

## 2. Objetivo da Entrega

### Efeitos Rúnicos

- Chance de ativação baseada no atributo Sorte.
- 7 efeitos implementados, um ou mais por arma.
- Feedback visual e de texto ao ativar.
- Duração por turno para cada efeito.
- IA responde a efeitos ativos (ex: não usa item bloqueado).

### Itens Secundários (com arma de 1 mão)

- Escudo.
- Livro de Cura.
- Orbe de Camuflagem.
- Totem de Proteção.
- Construtor Rúnico (placeholder — lógica completa na v0.7.0).

### Consumíveis (máximo 3 por partida)

- Teleporte.
- Cura individual (não consome turno).
- Gelo (imobiliza 1 turno).
- Invisibilidade.
- Disparo de Calibração.

---

## 3. Escopo

### Dentro do escopo

- `RunicEffectSystem` (TypeScript puro).
- 7 efeitos rúnicos com duração e comportamento.
- `StatusEffectManager` para aplicar/remover efeitos por turno.
- `SecondaryItemSystem` com 5 itens secundários.
- `ConsumableSystem` com 5 consumíveis e regra de 3 por partida.
- Regra: consumível que precisa ser atirado consome turno.
- HUD de efeitos ativos (ícones + turnos restantes).
- Feedback visual de ativação rúnica (flash/partícula simples).
- Debug: forçar ativação de efeito, selecionar consumíveis.

### Fora do escopo

- Construção de terreno completa (Construtor Rúnico — v0.7.0).
- Teleporte aliado (requer multiplayer — v0.9.0).
- Cura em massa (requer multiplayer — v0.9.0).

## 4. Efeitos Rúnicos

```ts
export type RunicEffectType =
  | 'BLEED'           // sangramento: perde % HP por N turnos
  | 'FREEZE'          // imobilização: não pode mover por N turnos
  | 'BLIND'           // cegueira: não vê ângulo por N turnos
  | 'WEAK_SHOT'       // fraqueza: força limitada a 40% por N turnos
  | 'ITEM_BLOCK'      // bloqueio de itens por N turnos
  | 'RANDOM_TELEPORT' // teleporte aleatório no mapa
  | 'VULNERABILITY';  // recebe mais dano por N turnos

export interface RunicEffect {
  type: RunicEffectType;
  duration: number;        // turnos restantes
  value?: number;          // ex: % de HP para sangramento
}
```

### Efeito por Arma

| Arma | Efeito Rúnico |
|---|---|
| Canhão | VULNERABILITY (2 turnos) |
| Arco Longo | BLIND (1 turno) |
| TNT | RANDOM_TELEPORT |
| Boomerangue | VULNERABILITY (1 turno) |
| Livro de Gelo | FREEZE (2 turnos) |
| Poções | BLEED (2 turnos, 5% HP/turno) |

## 6. Regras de Ativação Rúnica

```ts
function rollRunicEffect(luck: number): boolean {
  const chance = Math.min(0.05 + luck * 0.003, 0.75);
  return Math.random() < chance;
}
```

## 8. Consumíveis

| Consumível | Função | Usa turno? |
|---|---|---|
| Teleporte | Atirar → vai para ponto de impacto | Sim |
| Cura Individual | Cura 25% HP máximo instantâneo | Não |
| Gelo | Atirar → imobiliza alvo 1 turno | Sim |
| Invisibilidade | Invisível por 1 turno | Não |
| Disparo de Calibração | Atirar → mostra linha de referência | Sim |

**Regra:** máximo 3 consumíveis equipados por partida.

---

## 9. Impacto dos Efeitos no Gameplay

| Efeito | Impacto |
|---|---|
| BLIND | HUD de ângulo fica oculto para o alvo |
| FREEZE | Movimento bloqueado, mas ainda pode atirar |
| WEAK_SHOT | Barra de força limitada a 40% visualmente |
| ITEM_BLOCK | Ícones de itens ficam desabilitados na HUD |
| BLEED | HP reduz no início de cada turno afetado |
| VULNERABILITY | Próximos danos recebidos × 1.5 |
| RANDOM_TELEPORT | Posição é redistribuída aleatoriamente no mapa |
