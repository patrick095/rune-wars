# v0.1.0 — Setup Jogável Local

> **Status:** Planejado
> **Fase:** 0 — Protótipo Técnico
> **Objetivo:** Angular + Phaser rodando no navegador, com canvas responsivo, personagem básico e botão de reinício. Sem backend obrigatório.

---

## 1. Resumo

Primeira versão executável do Rune Wars. O jogo deve abrir no navegador desktop e mobile sem nenhuma dependência de backend. O resultado é um canvas com personagem e inimigo desenhados de forma simples, com tela de debug e botão de reinício. Esta versão valida que a stack Angular + Phaser funciona no ambiente do projeto.

---

## 2. Objetivo da Entrega

- Projeto Angular criado e funcionando.
- Phaser integrado como componente dentro de uma rota `/playground`.
- Canvas responsivo que funciona no mobile e no desktop.
- Dois sprites simples (jogador e inimigo) posicionados no mapa.
- Tela de debug inicial com informações básicas.
- Botão de reiniciar partida.
- Toda configuração de infraestrutura no Docker, subindo com um único comando.

## 5. Módulos e Componentes

### Angular

| Módulo / Componente | Responsabilidade |
|---|---|
| `AppModule` | Root module, roteamento base |
| `PlaygroundModule` | Rota `/playground`, carrega Phaser |
| `PhaserContainerComponent` | Hospeda o canvas do Phaser |
| `DebugOverlayComponent` | Overlay com informações de debug |

### Phaser (dentro de `PlaygroundModule`)

| Classe / Cena | Responsabilidade |
|---|---|
| `BootScene` | Preload de assets básicos |
| `PlaygroundScene` | Cena principal com sprites e botão de reinício |

## 11. Riscos

| Risco | Mitigação |
|---|---|
| Incompatibilidade Angular + Phaser em SSR | Desabilitar SSR para rotas de jogo |
| Phaser não detectar canvas em mobile | Forçar `WebGL` com fallback `Canvas` |
| Docker hot reload lento | Usar volume bind mount para desenvolvimento |
