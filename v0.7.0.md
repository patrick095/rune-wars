# v0.7.0 — Construção de Terreno e Academia

> **Status:** Planejado
> **Fase:** 7 + 8 — Engenheiro + Treino
> **Depende de:** [v0.6.0](./v0.6.0.md)
> **Objetivo:** Completar o Construtor Rúnico com lógica real de criação de terreno, e criar a Academia para treino livre de mecânicas.

---

## 1. Resumo

Duas entregas nesta versão. A primeira finaliza o Construtor Rúnico do item secundário: o projétil pode gerar terreno ao longo da trajetória (Linha Rúnica) ou criar um bloco fixo no primeiro impacto (Bloco Rúnico). A segunda entrega cria a Academia — uma tela de treino com campo de tiro, alvos fixos e móveis, e modo livre sem derrota, para aprender e testar todas as mecânicas do jogo.

---

## 2. Objetivos da Entrega

### Construção de Terreno (Construtor Rúnico)

- Modo Linha Rúnica: terreno gerado ao longo da trajetória do projétil.
- Modo Bloco Rúnico: bloco fixo criado no primeiro impacto.
- Terreno criado não sofre gravidade.
- Terreno criado pode ser destruído.
- Limite de construção por jogador (anti-abuso).
- Diferença visual entre terreno criado e natural.

### Academia

- Campo de tiro livre com escolha de arma, vento e consumíveis.
- Alvos fixos e móveis no mapa.
- Tutorial visual de ângulo e força.
- Modo treino sem derrota (infinito).
- Escolher vento manualmente.
- Testar efeitos rúnicos.

---

## 3. Escopo

### Dentro do escopo

**Construtor Rúnico:**
- Dois modos: Linha e Bloco.
- Geração de células no `TerrainEngine` como `CONSTRUCTED`.
- Limite de 20 células construídas por jogador por partida.
- Células construídas com cor/textura diferente.
- Destruição normal de células construídas.

**Academia:**
- Rota Angular `/academy`.
- Cena Phaser `AcademyScene` com campo de tiro.
- Alvos fixos (estáticos) e móveis (andam horizontalmente).
- Painel de configuração: arma, vento, consumíveis, efeito rúnico.
- Contador de acertos/erros.
- Tutorial visual (seta de ângulo, barra de força, indicador de vento).
- Sem HP do jogador (modo treino).

### Fora do escopo

- Construção em dungeon (v0.8.0+).
- Tutorial obrigatório do jogo (v1.0.0).
- Desafios de precisão ranqueados (v1.0.0).
- Tutoriais guiados com narração.

## 4. Construtor Rúnico — Lógica

### Novo Material no TerrainEngine

```ts
export enum TerrainMaterial {
  EMPTY = 0,
  DESTRUCTIBLE = 1,
  INDESTRUCTIBLE = 2,
  CONSTRUCTED = 3,  // novo: criado por jogador
}
```

### Modo Linha Rúnica

```ts
// A cada N pixels percorridos pelo projétil:
// Registra a célula do grid naquela posição como CONSTRUCTED
// Máximo de células construídas por jogador = construcionLimit
function drawRunicLine(
  projectilePath: Vector2[],
  terrainEngine: TerrainEngine,
  playerId: string,
  limit: number
): void { ... }
```

### Modo Bloco Rúnico

```ts
// Ao primeiro impacto do projétil:
// Cria área N×N de células CONSTRUCTED ao redor do impacto
function placeRunicBlock(
  impactX: number, impactY: number,
  size: number,
  terrainEngine: TerrainEngine,
  playerId: string,
  limit: number
): void { ... }
```

### Rastreamento por Jogador

```ts
// TerrainEngine deve rastrear quantas células cada jogador construiu
private constructedByPlayer: Map<string, number>;

// Impedir criar se limite atingido
if (constructedByPlayer.get(playerId) >= limit) return;
```

## 5. Academia — Estrutura da Cena

### Componentes Angular

| Componente | Função |
|---|---|
| `AcademyPageComponent` | Rota `/academy`, menu inicial |
| `AcademyHudComponent` | Painel de configuração lateral |

### Cenas Phaser

| Cena | Função |
|---|---|
| `AcademyScene` | Campo de tiro com alvos |

### Alvos

```ts
export interface AcademyTarget {
  x: number;
  y: number;
  width: number;
  height: number;
  hp: number;
  moving: boolean;
  moveSpeed?: number;     // pixels/s
  moveRange?: number;     // distância de oscilação
}
```

### Modos de Treino

| Modo | Descrição |
|---|---|
| Campo Livre | Atirar à vontade, sem objetivo |
| Alvos Fixos | 5 alvos estáticos, contar acertos |
| Alvos Móveis | 3 alvos em movimento, cronometrado |
| Treino Rúnico | Forçar efeito, praticar resposta |

|---|---|

---

## 9. Riscos

| Risco | Mitigação |
|---|---|
| Linha rúnica criando células demais e impactando performance | Limitar células por tiro + limite por jogador |
| Alvos móveis saindo do mapa | Definir bounds horizontais com bounce |
| Tutorial visual sendo intrusivo | Só exibir no primeiro acesso (flag no localStorage) |
