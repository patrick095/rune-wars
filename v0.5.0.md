# v0.5.0 — Personagem Customizável e Atributos

> **Status:** Planejado
> **Fase:** 4 — Testar Builds Sem Login e Sem Banco
> **Depende de:** [v0.4.0](./v0.4.0.md)
> **Objetivo:** Permitir customização completa do personagem para testes — atributos, nível, build — tudo salvo em localStorage, com presets prontos.

---

## 1. Resumo

Sem criar conta ou banco de dados, o jogador deve poder montar sua build completa: distribuir pontos em Força, Agilidade, Vitalidade e Sorte, ver o impacto calculado em dano, defesa, HP e mobilidade, e salvar a configuração localmente. Esta versão valida o sistema de atributos e cria os fundamentos para requisitos de armas.

---

## 2. Objetivo da Entrega

- Painel de customização do personagem acessível antes e durante a partida (no debug).
- 4 atributos: Força, Agilidade, Vitalidade, Sorte.
- Nível editável de 1 a 100 (concede 4 pontos por nível).
- Recálculo em tempo real de: dano, defesa, HP, mobilidade, chance de efeito rúnico.
- Requisitos de armas validados: se não cumprir o mínimo de atributo, a arma fica indisponível.
- Salvar build no localStorage.
- 5 presets: DPS, Tank, Sorte, Escavador, Engenheiro.

## 4. Atributos e Fórmulas

```ts
export interface PlayerStats {
  level: number;              // 1-100
  strength: number;           // pontos alocados
  agility: number;
  vitality: number;
  luck: number;

  // Derivados (calculados por AttributeCalculator)
  readonly maxHp: number;
  readonly damage: number;          // multiplicador de dano
  readonly defense: number;         // redução percentual de dano recebido
  readonly mobility: number;        // pixels por turno que pode se mover
  readonly runicChance: number;     // % chance de ativar efeito rúnico
}
```

### Fórmulas Sugeridas

```ts
// HP base 200, +20 por ponto de Vitalidade
maxHp = 200 + vitality * 20;

// Dano: multiplicador base 1.0, +0.02 por ponto de Força
damage = 1.0 + strength * 0.02;

// Defesa: redução de 0.5% por ponto de Agilidade, máx 60%
defense = Math.min(agility * 0.005, 0.6);

// Mobilidade: 30px base, +2px por ponto de Agilidade
mobility = 30 + agility * 2;

// Chance rúnica: 5% base, +0.3% por ponto de Sorte
runicChance = Math.min(0.05 + luck * 0.003, 0.75);
```

## 5. Pontos por Nível

```ts
// Pontos totais disponíveis para nível N:
const totalPoints = (level - 1) * 4;

// Validação: soma dos atributos não pode exceder totalPoints
const usedPoints = strength + agility + vitality + luck;
if (usedPoints > totalPoints) throw new Error('Pontos insuficientes');
```

## 6. Requisitos de Armas

```ts
// Na WeaponDefinition (adicionada nesta versão):
export interface WeaponRequirements {
  minStrength?: number;
  minAgility?: number;
  minVitality?: number;
  minLuck?: number;
  minLevel?: number;
}

// Validação:
export function canUseWeapon(stats: PlayerStats, weapon: WeaponDefinition): boolean {
  const req = weapon.requirements;
  if (!req) return true;
  return (
    (!req.minStrength || stats.strength >= req.minStrength) &&
    (!req.minAgility  || stats.agility  >= req.minAgility)  &&
    (!req.minVitality || stats.vitality >= req.minVitality) &&
    (!req.minLuck     || stats.luck     >= req.minLuck)     &&
    (!req.minLevel    || stats.level    >= req.minLevel)
  );
}
```
