# v0.8.0 — Dungeon Local Simulada

> **Status:** Planejado
> **Fase:** 9 — PvE Testável Antes do Backend
> **Depende de:** [v0.7.0](./v0.7.0.md)
> **Objetivo:** Implementar a Dungeon completa com IA de monstros, Andar 1 completo, lobby entre fases, chefe e sistema de recompensas local.

---

## 1. Resumo

Esta versão entrega o primeiro andar da Dungeon principal, jogável localmente sem backend. O jogador enfrenta monstros com IA progressiva, passa por fases com objetivo, enfrenta o chefe e recebe recompensas locais (sem persistência online). O lobby entre fases permite trocar armas e itens. É a validação final do PvE antes de conectar o backend.

---

## 2. Objetivo da Entrega

- Andar 1 completo: 3 fases (Entrada da Caverna, Salão dos Morcegos, Golem Menor).
- Lobby de dungeon entre fases (trocar armas/itens/consumíveis).
- IA de monstros com 3 comportamentos básicos.
- Sistema de fases com objetivo (derrotar inimigos / proteger cristal).
- Chefe (Golem Menor) com mecânica simples de troca de fase de vida.
- Recompensas locais ao vencer (XP local, ouro local).
- Trilha de dificuldade: apenas Iniciados nesta versão.

---

## 3. Escopo

### Dentro do escopo

- `DungeonEngine` (TypeScript puro) gerenciando estado de dungeon.
- 3 fases do Andar 1 com mapas distintos.
- IA de monstros: básica, intermediária, chefe.
- Lobby de dungeon entre fases.
- Sistema de objetivos: derrotar todos / proteger cristal.
- Golem Menor com 2 fases de comportamento (100%→50%, 50%→0).
- Recompensas locais: XP e ouro no localStorage.
- Contagem de vidas/tentativas: 3 tentativas por andar.

### Fora do escopo

- Andares 2-5.
- Trilhas de dificuldade Aventureiro+.
- Multiplayer cooperativo na dungeon (v1.0.0).
- Persistência de progresso no backend (v0.9.0+).
- Drops de itens reais (v1.0.0).
- Lobby com múltiplos jogadores.

## 4. Estrutura do Andar 1

### Fase 1 — Entrada da Caverna

**Objetivo:** derrotar 4 monstros simples.

```ts
const fase1: DungeonPhase = {
  id: 'floor1-phase1',
  name: 'Entrada da Caverna',
  objective: { type: 'DEFEAT_ALL', count: 4 },
  enemies: [
    { type: 'CAVE_CREATURE_BASIC', count: 4, ai: AiLevel.EASY }
  ],
  map: 'dungeon-cave-entrance',
};
```

**Mecânicas ensinadas:** movimento, vento, tiro, terreno destrutível.

### Fase 2 — Salão dos Morcegos

**Objetivo:** proteger cristal por 5 turnos.

```ts
const fase2: DungeonPhase = {
  id: 'floor1-phase2',
  name: 'Salão dos Morcegos',
  objective: { type: 'PROTECT', turns: 5, targetId: 'crystal' },
  enemies: [
    { type: 'BAT_SWARM', count: 6, ai: AiLevel.EASY, spawnWave: true }
  ],
  map: 'dungeon-cave-hall',
};
```

**Mecânicas:** posicionamento, cobertura, controle de área.

### Fase 3 — Covil do Golem Menor (Chefão)

**Objetivo:** derrotar o Golem Menor.

```ts
const fase3: DungeonPhase = {
  id: 'floor1-boss',
  name: 'Covil do Golem Menor',
  objective: { type: 'DEFEAT_BOSS', bossId: 'golem-minor' },
  enemies: [
    { type: 'GOLEM_MINOR', count: 1, ai: AiLevel.BOSS }
  ],
  map: 'dungeon-cave-boss',
};
```

## 5. IA de Monstros

```ts
export enum AiLevel {
  EASY,
  INTERMEDIATE,
  BOSS,
}

export interface MonsterAi {
  level: AiLevel;
  aimErrorDegrees: number;      // margem de erro no ângulo
  forceErrorPercent: number;    // margem de erro na força
  usesCover: boolean;           // usa terreno como cobertura
  targetsWeakest: boolean;      // prioriza alvo com menos HP
  phaseThresholds?: number[];   // % de HP para mudar comportamento
}
```

| Nível | Erro Ângulo | Erro Força | Usa Cobertura | Prioriza Fraco |
|---|---|---|---|---|
| EASY | ±20° | ±25% | Não | Não |
| INTERMEDIATE | ±10° | ±15% | Sim | Não |
| BOSS | ±5° | ±8% | Sim | Sim |

### Fases do Golem Menor

- **100%–50% HP:** ataques normais, pedras caindo (explosão de cima para baixo).
- **50%–0% HP:** começa a destruir cobertura destrutível próxima ao jogador.

## 7. Lobby de Dungeon

- Tela Angular exibida entre fases.
- Mostra resultado da fase anterior (vitória/derrota parcial).
- Permite trocar arma, item secundário e consumíveis.
- Mostra HP atual do jogador.
- Botão "Continuar" inicia próxima fase.
- Botão "Abandonar" volta ao menu.

## 10. QA — Cenários de Teste

| Cenário | Resultado esperado |
|---|---|
| Completar Fase 1 | Lobby aparece, fase 2 disponível |
| Deixar cristal ser destruído na Fase 2 | Fase falha, tentativa decrementada |
| Reduzir Golem a 50% | Comportamento muda visivelmente |
| Perder 3 vezes | Tela de falha exibida, volta ao menu |
| Vencer o Andar 1 | Recompensas salvas, tela de vitória |
| Trocar arma no lobby | Nova arma usada na próxima fase |

## 11. Riscos

| Risco | Mitigação |
|---|---|
| IA do chefe muito difícil sem multiplayer | Reduzir precision do boss para solo |
| Fase 2 (proteger cristal) sem aliados confusa | Instruções claras no início da fase |
| Performance com muitos monstros | Limitar monstros simultâneos a 6 |
