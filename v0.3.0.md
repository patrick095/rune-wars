# v0.3.0 — Terreno Destrutível e Indestrutível

> **Status:** Planejado
> **Fase:** 2 — Principal Diferencial do Jogo
> **Depende de:** [v0.2.0](./v0.2.0.md)
> **Objetivo:** Validar o diferencial central do Rune Wars — terreno que pode ser destruído ou que resiste, com personagens se reposicionando automaticamente.

---

## 1. Resumo

O terreno é o coração estratégico do Rune Wars. Esta versão implementa a engine de terreno com dois materiais distintos: destrutível e indestrutível. Explosões removem blocos destrutíveis. Blocos indestrutíveis resistem a qualquer dano. Personagens caem quando perdem suporte abaixo. A câmera e o gameplay devem continuar funcionando corretamente com terreno dinâmico.

---

## 2. Objetivo da Entrega

- Mapa com áreas de material destrutível (terra, areia, pedra mole).
- Mapa com áreas de material indestrutível (rocha sólida, metal) com textura visual distinta.
- Explosão do projétil remove terreno destrutível em área circular.
- Projétil não remove terreno indestrutível.
- Personagens caem quando o terreno sob eles é destruído.
- Personagens se reposicionam no chão mais próximo após queda.
- Debug permite alternar materiais e testar explosões.

---

## 3. Escopo

### Dentro do escopo

- `TerrainEngine` (TypeScript puro) com:
  - Grid de materiais por célula.
  - Tipos: `EMPTY`, `DESTRUCTIBLE`, `INDESTRUCTIBLE`.
  - Método de explosão: remove células em raio.
  - Método de query: "qual o chão abaixo de X,Y?".
- Renderização do terreno no Phaser (Tilemap ou pixel map).
- Textura visual diferenciada para cada material.
- Física de queda do personagem ao perder suporte.
- Integração com `ProjectilePhysics` (explosão chama `TerrainEngine`).
- Debug: alterar material de uma área, testar explosão manual.

### Fora do escopo

- Terreno construtível (v0.7.0).
- Múltiplas camadas de terreno.
- Terreno gerado proceduralmente (mapa é fixo nesta versão).
- Efeitos de partícula avançados na explosão.

---

## 4. Abordagem Técnica

### Representação do Terreno

Usar grid de células com enum de material. Cada célula é um quadrado de N pixels.

```ts
// terrain-engine.ts
export enum TerrainMaterial {
  EMPTY = 0,
  DESTRUCTIBLE = 1,
  INDESTRUCTIBLE = 2,
}

export interface TerrainCell {
  x: number;    // índice coluna
  y: number;    // índice linha
  material: TerrainMaterial;
}

export class TerrainEngine {
  private grid: TerrainMaterial[][];

  explode(centerX: number, centerY: number, radius: number): TerrainCell[] {
    // Remove DESTRUCTIBLE em raio circular
    // Retorna lista de células alteradas para o Phaser atualizar visual
  }

  getMaterialAt(worldX: number, worldY: number): TerrainMaterial { ... }

  getFloorBelow(worldX: number, worldY: number): number | null { ... }
}
```

### Tamanho de Célula Sugerido

- Célula: 8×8 pixels.
- Mapa: 100×40 células = 800×320 pixels base.
- Escalar conforme viewport.

### Renderização no Phaser

Opções:
1. `Graphics` com retângulos por célula (simples, para MVP).
2. `RenderTexture` atualizando pixels (performático, para evolução).

Usar opção 1 no MVP. Refatorar para opção 2 se performance cair.

## 6. Mapas desta Versão

### Mapa 1 — Planície Simples

- Chão plano destrutível.
- Rocha indestrutível no fundo e nas laterais.
- Duas colinas destrutíveis centrais.
- Objetivo: validar explosão e queda básica.

### Mapa 2 — Castelo Rúnico

- Plataformas indestrutíveis em diferentes alturas.
- Solo misto (destrutível no centro, indestrutível nas bordas).
- Objetivo: testar cobertura indestrutível e movimentação após explosão.

---

## 7. Comportamento de Queda

```
1. Projétil explode → TerrainEngine remove células.
2. TerrainEngine notifica posições afetadas.
3. Phaser verifica se personagem perdeu suporte (getMaterialAt(x, y+1) == EMPTY).
4. Se perdeu suporte: aplicar velocidade de queda até encontrar chão.
5. Personagem aterrissa no novo chão.
6. Nenhuma queda mata diretamente (sem dano de queda nesta versão).
```

## 9. Critérios de Aceite

- [ ] Terreno destrutível é removido visualmente pela explosão.
- [ ] Terreno indestrutível não é afetado pela explosão.
- [ ] Texturas visuais distintas para cada material.
- [ ] Personagem cai quando perde suporte.
- [ ] Personagem pousa no novo chão sem travar.
- [ ] Explosão não afeta células além do raio definido.
- [ ] Debug permite pintar e explodir em tempo real.
- [ ] Jogo continua funcionando após múltiplas explosões.

## 10. QA — Cenários de Teste

| Cenário | Resultado esperado |
|---|---|
| Atirar no terreno destrutível | Área circular removida visualmente |
| Atirar na rocha indestrutível | Nenhuma alteração no terreno |
| Destruir o chão sob o personagem | Personagem cai até novo suporte |
| Destruir área grande com debug | Múltiplas células removidas sem crash |
| Personagem sobre pedaço flutuante | Cai após a base ser destruída |
| Resetar mapa via debug | Terreno volta ao estado inicial |

---

## 11. Riscos

| Risco | Mitigação |
|---|---|
| Performance baixa com muitas células renderizadas | Usar `RenderTexture` e dirty flag |
| Personagem atravessando terreno durante queda | Raycast simples de colisão |
| Inconsistência entre grid lógico e visual | Grid lógica é fonte da verdade; visual sincroniza |
