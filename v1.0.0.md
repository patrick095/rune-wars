# v1.0.0 — Lançamento: Sistemas Completos

> **Status:** Planejado
> **Fase:** 12 — Sistemas Avançados
> **Depende de:** [v0.9.0](./v0.9.0.md)
> **Objetivo:** Primeira versão completa do Rune Wars com PvP ranqueado, XP/nível real, progressão de personagem, guildas, mercado entre jogadores, craft, upgrade, dungeons completas e rankings persistentes.

---

## 1. Resumo

A v1.0.0 é o lançamento público do Rune Wars. Com o core gameplay validado e o backend funcionando desde a v0.9.0, esta versão adiciona todos os sistemas que transformam o jogo de um PvP funcional em um MMORPG completo: progressão real, economia, comunidade e conteúdo de longo prazo.

---

## 2. Sistemas da v1.0.0

Esta versão é grande e deve ser implementada em sub-milestones internos. Os sistemas são:

1. **Progressão Real** — XP, level-up automático, pontos de atributo reais.
2. **Inventário Completo** — equipar armadura, capacete, botas, acessórios.
3. **PvP Ranqueado** — 1v1 e duplas com sistema de pontos.
4. **Rankings** — diário, semanal, mensal, geral (solo + duplas + guildas).
5. **Dungeon Completa** — Andares 1–5 com todas as trilhas de dificuldade.
6. **Craft e Upgrade** — receitas, materiais, pedras de upgrade.
7. **Mercado** — compra e venda entre jogadores.
8. **Guildas** — criação, membros, cargos, XP, banco, bônus PvE.
9. **PvP de Guildas** — até 4v4, ranking de guildas.
10. **Raças** — bônus raciais na criação de personagem.

## 3. Progressão Real

### XP e Nível

```ts
// XP necessário por nível (curva quadrática suave)
function xpForLevel(level: number): number {
  return Math.floor(100 * level * level * 0.5);
}

// Ao ganhar XP:
// - Verifica se atingiu xpForLevel(level + 1)
// - Se sim: level++, concede 4 pontos de atributo
// - Registra no banco
```

### Sistema de Pontos (ELO simplificado)

```ts
// K = fator de variação
// Ganho ao vencer: K * (1 - expectedWinRate)
// Perda ao perder: K * expectedWinRate

const expectedWinRate = 1 / (1 + Math.pow(10, (opponentRating - playerRating) / 400));
```

## 9. Mercado

### Funcionalidades

- Listar item à venda com preço em ouro.
- Comprar item de outro jogador.
- Cancelar listagem.
- Histórico de transações.
- Busca por tipo, raridade, arma.
- Taxa de transação: 5% de ouro (anti-inflação).

### Regras

- Apenas itens **transferíveis** podem ser vendidos.
- Item vinculado ao equipar: pode ser vendido enquanto não equipado.
- Não transferível: nunca aparece no mercado.

### Backend

```ts
export interface MarketListing {
  id: string;
  sellerId: string;
  itemInstanceId: string;
  price: number;
  createdAt: Date;
  expiresAt: Date;    // 7 dias
}
```

## 10. Guildas

### Funcionalidades

| Funcionalidade | Detalhe |
|---|---|
| Criação | Nome único, 3 membros mínimos |
| Membros | Limite por nível da guilda |
| Cargos | Lider, Oficial, Membro |
| XP de guilda | Ganho por dungeons com membros |
| Nível de guilda | Aumenta limite de membros e acesso a construções |
| Banco da guilda | Depósito de itens/ouro para membros |
| Chat de guilda | Mensagens em tempo real (WebSocket) |
| Bônus PvE | Percentual de XP/drop extra em dungeon com membros |

### PvP de Guildas (4v4)

- Modo separado do ranqueado individual.
- Marcação de data entre guildas.
- Ranking de guildas com pontos.
- Recompensas cosméticas e de prestígio.
- Bônus de guilda não interferem no ranqueado individual.

## 12. Segurança

- Backend é a fonte da verdade para todo dano, drop, recompensa.
- Nunca confiar em valores enviados pelo cliente.
- Rate limiting em todas as ações de partida.
- Validar itens equipados antes de cada ação de batalha.
- Logs de todas as transações de mercado para auditoria.
- Proteção contra bots em matchmaking (detecção de padrão de ação).

## 15. Riscos

| Risco | Mitigação |
|---|---|
| Economia inflacionária | Taxa de mercado + itens com durabilidade |
| Pay-to-win por pressão | Proibir venda direta de poder no cash shop por política |
| Dungeon multiplayer com lag | Servidor autoritativo de turno, cliente prevê |
| Bot farming de ouro/XP | Rate limiting, detecção de padrão e suspensão |
| Churn de jogadores sem conteúdo pós-v1.0 | Roadmap pós-lançamento com novos andares e eventos |
