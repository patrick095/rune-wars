# v0.2.0 — Tiro, Vento e IA Local

> **Status:** Planejado
> **Fase:** 1 — PvP Local Contra IA
> **Depende de:** [v0.1.0](./v0.1.0.md)
> **Objetivo:** Simular um PvP completo contra IA com turnos, ângulo, força, vento, HP, dano, vitória e derrota. Sem backend.

---

## 1. Resumo

Esta versão transforma o canvas vazio da v0.1.0 em um jogo jogável. O jogador enfrenta uma IA local em PvP por turnos. O tiro obedece física parabólica influenciada por vento variável. O jogo exibe HP, turno, vento e resultado. O painel de debug permite alterar parâmetros em tempo real.

---

## 2. Objetivo da Entrega

- Sistema de turnos alternados (jogador → IA → jogador...).
- Controle de ângulo e força pelo jogador.
- Projétil com trajetória parabólica.
- Vento com direção e intensidade, mudando a cada turno.
- HP de cada personagem.
- Cálculo de dano básico com multiplicador de distância.
- IA simples que calcula e atira.
- Telas de vitória e derrota.
- Painel de debug completo.

---

## 3. Escopo

## 4. Módulos TypeScript Puro (sem Phaser)

Toda lógica de jogo deve ficar em TypeScript puro, desacoplada do Phaser.

```
system/frontend/src/app/shared/
  game-core/
    turn-manager.ts        ← gerencia turnos
    wind-system.ts         ← gera e aplica vento
    damage-calculator.ts   ← fórmula de dano
    projectile-physics.ts  ← física da parábola
    ai-local.ts            ← IA simples
    player-stats.ts        ← interface PlayerStats
    projectile-config.ts   ← interface ProjectileConfig
```

## 5. Interfaces de Contrato

```ts
// player-stats.ts
export interface PlayerStats {
  hp: number;
  maxHp: number;
  x: number;
  y: number;
  isPlayer: boolean;
}

// projectile-config.ts
export interface ProjectileConfig {
  angle: number;          // graus
  force: number;          // 0-100
  gravityScale: number;
  windInfluence: number;  // 0-1
  baseDamage: number;
}

// wind-system.ts
export interface WindState {
  direction: number;  // -1 (esquerda) a 1 (direita)
  intensity: number;  // 0-100
}
```

## 6. Lógica de Jogo

### Turnos

```
1. Início do turno do jogador.
2. Jogador ajusta ângulo e força.
3. Jogador confirma tiro.
4. Projétil calculado e animado.
5. Dano aplicado.
6. Vento muda.
7. Início do turno da IA.
8. IA calcula tiro com margem de erro.
9. Projétil calculado e animado.
10. Dano aplicado.
11. Vento muda.
12. Volta ao passo 1 ou exibe resultado.
```

### Física do Projétil

```ts
// A cada frame:
velocityX += windState.direction * windState.intensity * projectile.windInfluence * dt;
velocityY += GRAVITY * projectile.gravityScale * dt;
x += velocityX * dt;
y += velocityY * dt;
```

### Fórmula de Dano

```ts
const distancia = Math.sqrt((impactoX - alvoX) ** 2 + (impactoY - alvoY) ** 2);
const multiplicadorDistancia =
  distancia <= 10  ? 1.0  :
  distancia <= 30  ? 0.75 :
  distancia <= 60  ? 0.5  :
  distancia <= 100 ? 0.25 : 0;

const danoFinal = baseDamage * multiplicadorDistancia;
```

### IA Local

- Calcula ângulo ideal com base na posição do jogador.
- Aplica margem de erro aleatória (±10-20 graus, ±10-20 de força).
- Considera o vento atual para compensar trajetória.
- Dificuldades: Fácil (erro alto), Médio (erro médio), Difícil (erro baixo).

## 7. Painel de Debug

| Controle | Tipo | Função |
|---|---|---|
| Vento direção | Slider -100 a 100 | Altera direção e intensidade do vento |
| HP Jogador | Input numérico | Altera HP atual do jogador |
| HP IA | Input numérico | Altera HP atual da IA |
| Dano base | Input numérico | Altera dano base do projétil |
| Dificuldade IA | Select | Fácil / Médio / Difícil |
| Resetar partida | Botão | Reinicia a cena com configurações do debug |

## 8. UI/UX

- HUD de combate: HP jogador (esquerda), HP IA (direita), vento (centro-topo), turno atual.
- Controle de ângulo: botão + e - ou arrastar na tela (mobile).
- Controle de força: barra de power-up (toque e segura / clique).
- Indicador de trajetória: linha pontilhada estimada (baseada em ângulo, força e vento atual).
- Tela de vitória: overlay "VOCÊ VENCEU" + botão jogar novamente.
- Tela de derrota: overlay "VOCÊ PERDEU" + botão jogar novamente.

### Mobile-first

- Controles de ângulo e força como botões grandes na parte inferior.
- Vento exibido no centro superior com ícone de seta.
- Toque e segura para acumular força (igual Gunbound/DDTank).

## 10. QA — Cenários de Teste

| Cenário | Resultado esperado |
|---|---|
| Atirar com força máxima, ângulo 90° | Projétil sobe e cai em queda livre |
| Atirar com vento forte para direita | Projétil desvia visivelmente para direita |
| Reduzir HP da IA para 1 via debug e atirar | Jogo exibe vitória |
| Reduzir HP do jogador para 1 via debug | Próximo turno da IA finaliza com derrota |
| IA na dificuldade Difícil | Acerta com mais frequência do que Fácil |
| Resetar partida durante turno da IA | Cena reinicia sem travar |

---

## 11. Riscos

| Risco | Mitigação |
|---|---|
| Loop de física causando lentidão em mobile | Usar delta time fixo (60fps target) |
| IA travando em loop infinito de cálculo | Limitar tentativas da IA por turno |
| Controles de toque imprecisos | Testar em dispositivo real precocemente |
